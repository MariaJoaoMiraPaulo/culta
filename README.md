# Culta

A client-side rendering website built with Gatsby and powered by Contentful CMS.

## About This Project
This is the official Culta website, a client-side rendered application that combines Gatsby's powerful static site generation with Contentful's flexible headless CMS architecture to deliver dynamic cultural content experiences.

## How to run it

### Clone it 
```
git clone git@github.com:MariaJoaoMiraPaulo/culta.git
cd culta
``` 

### Install dependencies 
```
yarn i
```

### Environment Setup
Create a .env file in the root directory and add your Contentful credentials.

### Run the Development Server

```
yarn run jokie
```
